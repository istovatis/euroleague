Privacy Policy

Last updated: 22 October 2026

This policy explains what data the PARQUET HOOPS website and publishing tool handle. In short: we don't collect personal data from visitors or followers.

Website

This website is a static page hosted on GitHub Pages. We set no cookies and run no analytics or tracking. GitHub may log technical data such as IP addresses to operate its service; see GitHub's privacy statement.

Our publishing tool

The tool is used only by the account owner to publish our own content to our own accounts. To do that it holds access tokens for those accounts (Instagram, X and TikTok), issued when the owner authorizes the tool through each platform's official login (for TikTok: Login Kit). The tokens are stored as encrypted secrets, never in code, and are used only to:

  • confirm that the authorized account is our own brand account (for TikTok, using the user.info.basic scope: open ID and display name), and
  • upload our own videos to that account (for TikTok, using the video.upload scope, which sends a draft to the owner's inbox for manual posting).

We do not collect, store or share data about other users, followers or viewers. We read aggregate performance numbers of our own posts (such as reach and likes) to improve our content; these are kept privately and never shared.

Sharing

We do not sell or share any personal data.

Revoking access

The account owner can revoke the tool's access at any time in each platform's settings (for TikTok: Settings and privacy, Security, Manage app permissions).

Changes

We may update this policy; the date above shows the latest version.

Contact

For privacy questions, send a direct message to @parquet.hoops on Instagram, or open an issue at github.com/istovatis/euroleague.
